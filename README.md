# Learn Python: The Most Basic Tutorial

A hands-on, from-zero Python course. Each lesson explains one idea in plain language (ideas that exist in every programming language), shows it in Python, and gives you a fill-in-the-blank file to practise with.

## What's here

| Path | What it is |
|------|------------|
| [`TUTORIAL.md`](TUTORIAL.md) | 14 lessons: the idea, Python examples, and questions for each |
| `exercises/` | Practice files with blanks (`____`) for you to fill in. Each one checks itself. |
| `solutions/` | Completed versions of every exercise |
| [`ANSWERS.md`](ANSWERS.md) | Answers to every lesson's questions |

## Topics

1. Instructions and output (`print`, comments)
2. Variables
3. Data types (`int`, `float`, `str`, `bool`)
4. Operators (maths, comparison, `and`/`or`/`not`)
5. Input (`input()`)
6. Decisions: `if` / `elif` / `else`
7. Loops: `while` (with `break` and `continue`)
8. Loops: `for` and `range()`
9. Lists
10. Dictionaries
11. Functions
12. Strings in depth
13. Handling errors (`try` / `except`)
14. Final project: a grade calculator

## Quick start

```bash
python3 --version                  # check that Python 3 is installed
python3 exercises/02_variables.py  # run an exercise
```

Replace each `____` in the exercise file and run it again until you see **All checks passed!**

An error like `NameError: name '____' is not defined` just means there's still a blank to fill. Its line number shows you where.
